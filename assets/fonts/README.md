# 字体

页面文字用 12px 点阵字；地图里极小的字（招牌、小地图上的数字）仍用 9×9 点阵字。两份字体都放在项目里，离线也能正常显示。

## `FusionPixel12pxProportionalSC.woff2`

缝合像素字体 12px 比例 简体（Fusion Pixel Font 12px Proportional SC）v2024.05.12，作者 TakWolf。

- 原始仓库：https://github.com/TakWolf/fusion-pixel-font
- 取自 Fontsource 打包的版本：`https://cdn.jsdelivr.net/npm/@fontsource/fusion-pixel-12px-proportional-sc@5.3.0/files/fusion-pixel-12px-proportional-sc-latin-400-normal.woff2`（文件名里的 latin 只是 Fontsource 的命名，里面包含全部汉字）
- SHA-256：`043eae5e616b0d1e75dc746d3d687b4413f9f1c70c1a09bc4ebb705ef1cc8e32`
- 授权：见同目录 `FusionPixel12px-OFL.txt`（SIL OFL 1.1，免费使用、复制和分发，可商用；保留字体名“Fusion Pixel”，改动后的版本不能沿用这个名字）。
- 字号只用 6 的倍数（12、18、24、30、36、48px），这样在 Retina 屏上每个字体像素正好对齐整数个屏幕像素，字边不会发虚。
