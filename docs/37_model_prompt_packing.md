## 本次修复

只改变人物模型输入的传输表示。输出 Schema、候选数量、人物原始 ID、模型选择权、心理数学和世界结算保持原有合同。

- `expanded`：原格式，保留缩进，作为对照与回退。
- `compact`：去掉 JSON 排版空白；字符串内部的空格与换行保持原样。
- `shared`：在紧凑格式上，把完全相同且重复出现的大对象存入本条消息的 `shared` 字典；原位置通过 `$contextRef` 指向它。

共享标签是本条消息的传输标签，不是新的领域 ID。模型仍必须输出原始人物、证据、心理来源和候选 ID。独立的候选与引用短索引保留。字典来自已经完成个人感知投影的同一份输入，不从其他人物或其他会话补充信息。

当引用说明与字典的成本抵消节省，自动使用普通紧凑 JSON。源数据本身含有引用形状的字面对象时，同样回退，避免混淆。展开操作恢复独立的 JSON 值，不制造可变对象别名。

## 配置与复测

启动服务前可以设置 `GTOWN_CHARACTER_PROMPT_FORMAT=expanded|compact|shared`，默认是 `shared`。该选项只影响服务端的人物提示呈现，不改变调用次数与授权预算。复测上一份延迟报告的旧提示时，需显式指定 `--prompt-format expanded`。

复测使用同一个检查点，顺序执行：

```bash
npm run benchmark:model -- --run --call-mode two-call --prompt-format expanded --checkpoint /absolute/path/initial-checkpoint.json
npm run benchmark:model -- --run --call-mode two-call --prompt-format shared --checkpoint /absolute/path/initial-checkpoint.json
```

普通 `npm run benchmark:model` 只显示帮助，不调用模型。离线合同为 `npm run character-model-prompt-packing:test`。
