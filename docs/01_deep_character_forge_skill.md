# 深层角色铸造器 Skill

## 0. Skill 定位

本 Skill 用来建立有深度、可持续行动、内在多义的角色。

它不是普通“人设生成器”。它不以姓名、职业、性格、外貌、MBTI、背景故事为中心，而以角色在规定情境中的多重行动为中心。

它的目标是生成这样的角色：

- 公开说自己想做一件事，实际被另一种欲望拖拽。
- 做出高尚行为时混入占有、索取、虚荣或控制。
- 做出恶意行为时混入爱、恐惧、求救或自毁。
- 伤害别人时有短暂快感，快感之后又惩罚自己。
- 想被别人看见，又怨恨别人看穿自己。
- 不只是“有秘密”，而是不断篡改自己对秘密的解释。
- 能主动改变其他角色，而不是只承受剧情。

核心目标：

> 建立人物，不是建立标签。  
> 建立行动，不是建立设定。  
> 建立多义性，不是建立正确答案。

---

## 1. 适用场景

当用户需要以下任务时，使用本 Skill：

- 创建复杂角色。
- 深化扁平角色。
- 为小说、电影、剧集、游戏、戏剧、互动叙事创建人物。
- 诊断一个角色为什么普通、浅、单一、像工具人。
- 把“好人/坏人/受害者/反派/恋人/导师”等功能性角色改造成真正的人。
- 为角色生成可长期驱动故事的行动逻辑。
- 为角色生成与其他角色的互相污染关系。
- 生成角色的内心法庭、自我神话、羞耻机制、阴影行动和不可逆边界。

---

## 2. 理论基础

本 Skill 受斯坦尼斯拉夫斯基体系启发，但不把体系简化为“真实表演”或“心理说明”。

本 Skill 使用以下原则：

1. 角色不是性格，而是行动模式。
2. 行动不是外部动作，而是有目标、有阻力、有伪装、有潜台词的内在动作。
3. 人物的真实不来自“他说自己是谁”，而来自“他在压力下具体做什么”。
4. 人物不是单一欲望体，而是多重欲望的战场。
5. 道德、爱、责任、原则、牺牲、保护，都可能是欲望的伪装。
6. 恶意、报复、控制、诱导、冷漠，也可能混有爱、求救、恐惧和自毁。
7. 好角色不是更极端，而是更矛盾、更能自欺、更能行动。
8. 内心必须被转化成可表演行动。

## 3. 核心公式

普通角色公式通常是：

```text
背景 + 性格 + 目标 + 弱点 = 角色
```

本 Skill 禁止停留在这个层面。

深层角色公式是：

```text
规定情境
+ 自我神话
+ 不可承认的欲望
+ 羞耻机制
+ 防御语言
+ 阴影行动
+ 高尚能力
+ 关系饥饿
+ 不可逆边界
= 深层角色
```

进一步压缩为：

```text
角色 = 他声称自己在做的事
     + 他真正想做的事
     + 他不能承认自己想做的事
     + 他因此对别人做出的伤害
     + 他为伤害发明的高尚理由
```

## 6. 角色四线模型

每个主要角色必须拥有四条行动线。

```yaml
四条行动线:
  显性行动线:
    角色公开声称自己想做什么:
    角色希望别人如何理解自己:
    角色最常使用的体面理由:
    角色在公共场合的表演方式:

  欲望行动线:
    角色真正想得到什么:
    角色真正想靠近谁或什么:
    角色真正想被谁看见:
    角色真正想重新经历什么:
    角色真正想占有什么:
    角色真正想毁掉什么:

  防御行动线:
    角色如何否认自己的欲望:
    角色如何把欲望改名为道德、爱、责任、学术、原则、牺牲、正义或保护:
    角色如何攻击看穿自己的人:
    角色最常使用的自我辩护句:

  阴影行动线:
    角色实际正在伤害谁:
    角色如何诱导别人:
    角色如何利用自己被伤害的位置:
    角色如何用高尚获得权力:
    角色如何用受苦索取关注:
    角色如何在保护中占有:
    角色如何在忏悔中控制:
```

角色如果缺少任意一条行动线，则不合格。

## 7. 规定情境：外部与内部

规定情境不能只写外部条件。

```yaml
规定情境:
  外部规定情境:
    时间:
    地点:
    职业位置:
    权力关系:
    经济压力:
    声誉压力:
    依赖关系:
    逃离成本:
    当前风险:

  内部规定情境:
    自我神话:
    未完成的旧关系:
    不可承认的欲望:
    最怕被看穿的东西:
    最想被谁赦免:
    最不能忍受的普通性:
    最常重复的自欺:
    最深的羞耻:
```

内部规定情境必须能解释角色为什么不能简单离开、认错、道歉、逃避或解决问题。

## 8. 自我神话

自我神话是角色关于自己的核心谎言。

它不是普通信念，而是角色活下去、行动、爱人、伤人时必须维护的自我叙事。

```yaml
自我神话:
  角色相信自己是:
  角色必须证明自己是:
  角色最怕自己其实是:
  哪个人最能摧毁这个神话:
  角色为了维护神话会做什么:
  角色为了维护神话会牺牲谁:
```

示例：

```yaml
自我神话:
  角色相信自己是: 不被欲望支配的正直教师。
  角色必须证明自己是: 能把私人情感隔离在讲台之外的人。
  角色最怕自己其实是: 一个普通、脆弱、会被欲望牵动的男人。
  哪个人最能摧毁这个神话: 一个看穿他反复标准的学生。
  角色为了维护神话会做什么: 把偏心说成严格，把恐惧说成边界。
  角色为了维护神话会牺牲谁: 被他异常注意的人。
```

## 9. 欲望滞后规则

不要让道德先出现。先写欲望如何发生。

```yaml
欲望滞后:
  欲望第一次出现:
    它看起来像什么无害行为:
    角色如何享受它:
    角色为什么暂时不恐惧:

  道德迟到:
    角色在什么时候突然命名欲望:
    角色为什么感到羞耻:
    角色把羞耻转嫁给谁:
    道德如何不是拯救，而是扭曲欲望:

  欲望回流:
    禁止如何制造更精确的注意:
    回避如何成为另一种靠近:
    惩罚如何制造关系:
    补偿如何再次点燃欲望:
```

## 10. 羞耻机制

羞耻不是情绪说明，必须转化成行动。

```yaml
羞耻机制:
  角色因什么羞耻:
  角色羞耻时会攻击谁:
  角色羞耻时会冷淡谁:
  角色羞耻时会装作什么:
  角色羞耻时会做出的错误善举:
  角色羞耻后会如何补偿:
  补偿如何造成更大伤害:
```

禁止写：

```text
他感到羞耻。
```

必须写成：

```text
他把她最有力的发言判成“概念不清”，然后在夜里重读那段发言三遍。
```

## 11. 多重动机拆解

任何关键行动都不能只有一个动机。

```yaml
关键行动:
  行动:
  表层理由:
  欲望理由:
  羞耻理由:
  权力理由:
  自欺理由:
  对他人的真实影响:
  角色不愿承认的快感:
  角色事后的自我惩罚:
  对关系造成的不可逆痕迹:
```

示例：

```yaml
关键行动:
  行动: 教师公开否定学生的发言。
  表层理由: 她的概念不严谨。
  欲望理由: 他过度等待她开口，必须切断这种等待。
  羞耻理由: 他不能承认自己整堂课都在注意她。
  权力理由: 他需要重新占据教师高位。
  自欺理由: 他告诉自己这是严格训练。
  对他人的真实影响: 学生开始怀疑自己的能力。
  角色不愿承认的快感: 她终于被他影响。
  角色事后的自我惩罚: 他深夜打开她的作业，写了九页批注，又删掉七页。
  对关系造成的不可逆痕迹: 学生第一次意识到他不是普通严格，而是只对她反复无常。
```

## 12. 高尚行动污染检查

高尚行动必须检查阴影动机。

```yaml
高尚行动污染检查:
  行动:
  高尚解释:
  可能的自恋:
  可能的控制:
  可能的占有:
  可能的报复:
  可能的索取:
  可能的欲望延续:
  该行动对对方是否真的有利:
  对方是否被迫参与角色的自我净化:
```

如果一个角色的高尚行为完全干净，优先怀疑它太浅。

---

## 13. 恶意行动复杂化检查

恶意行动必须检查是否混入爱、恐惧、求救或自毁。

```yaml
恶意行动复杂化:
  行动:
  伤害对象:
  表面恶意:
  隐藏爱意:
  隐藏恐惧:
  隐藏求救:
  隐藏自毁:
  角色是否希望被阻止:
  角色是否希望被看穿:
```

如果一个角色的恶意只是恶意，优先怀疑它太扁。

---

## 14. 内心法庭

深层人物必须有内心法庭。

```yaml
内心法庭:
  角色控告自己什么:
  角色替自己辩护什么:
  角色故意隐瞒什么证据:
  角色伪造什么证据:
  角色希望谁审判自己:
  角色为什么又怨恨这个审判者:
  角色真正想要:
    无罪:
    惩罚:
    宽恕:
    被看见:
    被毁灭:
  角色最常说给自己听的判词:
```

人物不是“有内心冲突”，而是不断给自己开庭、作伪证、改口供。

## 15. 关系饥饿

人物的深度常常藏在他想从别人那里得到什么。

```yaml
关系饥饿:
  角色最想被谁看见:
  角色最想被谁误解:
  角色最想被谁原谅:
  角色最想惩罚谁:
  角色最想保护谁:
  角色最想让谁欠自己:
  角色最想从谁那里证明自己存在:
```

## 16. 触发器

触发器必须具体，能转换成场景。

```yaml
触发器:
  欲望触发:
    - 某个动作
    - 某句话
    - 某种沉默
    - 某个空间
    - 某个旧物

  羞耻触发:
    - 被看穿
    - 被感谢
    - 被拒绝理解
    - 被比较
    - 被当成普通人

  恶意触发:
    - 对方不按自己期待受伤
    - 对方拒绝成为赦免者
    - 对方把自己说得太准确
    - 对方转身离开

  高尚触发:
    - 对方真正无助
    - 旧日债务重现
    - 自己能牺牲却无人知道
    - 有机会停止伤害
```

## 18. 不可逆边界

角色必须有不可逆边界。

```yaml
不可逆边界:
  他一旦做了什么就再也不能回到原来的自我叙事:
  他一旦被谁看穿就无法再使用旧理由:
  他一旦伤害了谁就无法用道歉修复:
  他最可能毁掉:
  他最可能保护:
  他最可能误认为爱、正义、命运或牺牲的东西:
```

## 20. 反安全叙事规则

禁止以下角色默认处理：

- 好人犯错后及时改正。
- 坏人做坏事只是因为坏。
- 受害者只负责受伤和被保护。
- 爱慕者只负责爱慕。
- 反派只负责制造阻力。
- 导师只负责引导主角。
- 角色忏悔后自动变深。
- 角色痛苦后自动值得同情。
- 道德行动自动比欲望行动更真实。
- 欲望被消灭后角色获得净化。

如果出现以上倾向，必须增加多重动机、阴影行动和反行动。

## 21. 生成命令

### `/forge`

生成深层角色。

```text
/forge
角色概念:
场所:
关系对象:
希望黑暗度:
希望高尚度:
限制:
```

### `/deepen`

深化已有角色。

```text
/deepen
[粘贴角色设定]
```

### `/diagnose`

诊断角色是否扁平。

```text
/diagnose
[粘贴角色]
```

### `/action`

拆解一个角色动作的多重动机。

```text
/action
角色:
动作:
对象:
```

### `/court`

生成角色的内心法庭。

```text
/court
角色:
当前事件:
最怕被看穿:
```

### `/shadow`

生成角色阴影行动。

```text
/shadow
角色:
高尚身份:
欲望:
关系对象:
```

### `/relation`

生成两个角色的互相污染关系。

```text
/relation
角色A:
角色B:
场所:
初始关系:
```
