# 模拟真实性与停滞保护

1000回合旧样本的后段由固定模板生成移动与空对白；四名人物暂停后，剩余人物仍被推进到回合上限。该样本不能证明真实模型完成1000回合叙事模拟。

## 入口

真实模型测试使用 `npm run gemini:simulate`。人物阶段只能从程序发出的 API 请求取得，保存请求正文、原始响应、返回模型与用量，禁止失败后用模板替代。用户指定网关的返回模型是网关声明，不是独立的上游身份认证。继承的旧存档仍标记为未验证历史。

`runV27ModelRelay.mjs` 是外部提交入口，无法证明 JSON 作者身份。默认不再启动来源不明的中继；必须显式指定 `RELAY_RUN_PURPOSE=rehearsal` 才能提交外部回复。`RELAY_INPUT_KIND=fixture` 明确表示排练。即使输入声称来自模型，也不能把这个入口提升成真实模型测试。排练报告显示来源限制，`complete` 不再表达成功；回合上限用 `budgetReached` 单独表示。

这些是受支持程序入口的边界，不是防止拥有源码修改权限的人另写程序的安全沙箱。

## 人物暂停

共享运行时在每次决策前检查所有本场人物。任何人物进入 `suspended_model_error`，立即抛出 `SIMULATION_PARTICIPANT_UNAVAILABLE`，保留已接受阶段、预算、原因和存档，不再跳过此人继续调用其他人物。中继与 API 测试保存停机原因。

正常等待、睡眠和可被新证据唤醒的局部 `stalled` 不等同于模型异常，不会仅因这些状态关闭全场。修复后的恢复仍需原有显式授权；增加测试回合数不能恢复耗尽的预算。

## 重复循环

按已结算历史检查最近24个人物回合。如果其中至少12次公开行动只有最多3种“人物、动作、目的地、字面对白”组合，且没有工作、物品、资源等其他效果，则返回 `SIMULATION_NO_PROGRESS` / `stalled_no_progress`。全为私人维护的24回合也停下。

这是保守的重复检测，不是文学评分，也不能识别所有换词重复。新的对白、新的移动目的地或物理成果不会被这条规则当成同一种循环。检测从存档重建，重启不能清除；旧存档的移动目的地从对应世界结果恢复。命中后保留现场供诊断，不强制选择另一动作，不代写剧情。

报告先显示人物故障或停滞，再显示回合预算。`qualityVerdict` 固定为 `not_evaluated`，到达回合数不代表故事目标达成。历史 `modelCalls` 计数只表示阶段调用，不证明真实模型调用。

## 验证

`npm run simulation-integrity:test` 验证入口拒绝、暂停优先级、恢复存档中的往返循环，以及正常行路、新对白、实际工作不被误判。中继集成测试另验证首个人物暂停后不再产生其他人物请求，且重启、扩回合不能绕过。

不要直接覆盖1000回合旧证据。真实模型接续应选取可信检查点、新建输出目录，并明确记录未验证的继承历史。
