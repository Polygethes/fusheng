# 小镇场域生成器 Skill

## 0. Skill 定位

本 Skill 用来创建一个能让复杂人物持续发生故事的场所。

“小镇”不是背景板，而是压力机器。它可以是真正的小镇，也可以是大学、医院、剧团、律所、寺院、研究所、家族企业、电影片场、疗养院、豪宅、海岛、边境车站、地下俱乐部或任何封闭关系场。

它的任务不是提供风景，而是让人物：

- 频繁相遇。
- 难以逃离。
- 互相依赖。
- 保守秘密。
- 被谣言误读。
- 被制度压迫。
- 被空间触发旧事。
- 在公开体面与私下欲望之间分裂。
- 把高尚、卑劣、爱、恨、欺骗、保护、报复转化成行动。

---

## 1. 适用场景

当用户需要以下任务时，使用本 Skill：

- 为一组复杂人物创建叙事场所。
- 创建一个能持续生成冲突、秘密、谣言和关系变形的小镇。
- 为小说、剧集、游戏、互动叙事、AI 沙盘创建故事场域。
- 把人物放进一个无法轻易逃离的压力系统。
- 设计地点、制度、权力中心、共同秘密、历史伤口和事件触发器。
- 为“人物小镇”网页产品生成初始场所数据。

---

## 2. 核心原则

1. 场所不是背景，而是行动压力。
2. 空间必须让人物的欲望、羞耻、权力和秘密具体化。
3. 小镇必须有公开规则和潜规则。
4. 小镇必须有谣言系统。
5. 小镇必须有证据系统。
6. 小镇必须有共同历史伤口。
7. 小镇必须有无法轻易逃离的成本。
8. 每个重要空间都必须能触发某类人物阴影。
9. 每个公共事件都必须改变人物之间的关系。
10. 场所必须能够错误地命名私人关系。

---

## 3. 小镇核心公式

```text
封闭边界
+ 权力结构
+ 共同秘密
+ 谣言系统
+ 证据系统
+ 公共仪式
+ 私密空间
+ 逃离成本
= 可持续叙事场域
```

进一步：

```text
小镇 = 一台把私人欲望公共化、把公共秩序私人化的机器。
```

## 6. 小镇基础设定

```yaml
基础设定:
  名称:
  类型:
  时代:
  气质:
  外界如何看它:
  内部人如何看它:
  新来者最先误解什么:
  老住民最不愿承认什么:
```

气质不是风格词，而是行动压力。

错误：

```text
这个小镇阴郁、神秘、压抑。
```

正确：

```text
这个小镇要求所有人公开称赞彼此，私下却靠档案、流言和人情债互相控制。
```

## 7. 边界设计

小镇必须有边界。

```yaml
边界:
  地理边界:
    谁可以进入:
    谁可以离开:
    离开需要付出什么:

  社会边界:
    谁是内部人:
    谁是外来者:
    谁永远无法真正进入:
    谁被迫留下:

  心理边界:
    哪些话不能说:
    哪些关系不能被命名:
    哪些欲望必须伪装:
```

没有边界，人物就可以轻易逃离，故事会散。

---

## 8. 权力结构

```yaml
权力结构:
  明面权力:
    机构:
    负责人:
    权力来源:
    惩罚方式:

  暗面权力:
    谁掌握秘密:
    谁掌握档案:
    谁掌握人情债:
    谁掌握谣言:
    谁能毁掉别人但不留下痕迹:

  权力交易:
    什么可以交换:
    什么不能明说但一直在交换:
    谁依赖谁:
    谁欠谁:
```

权力必须具体到行动。

例如：

```yaml
明面权力: 教务处决定成绩复核。
暗面权力: 老教师微信群决定一个学生是否“难相处”。
```

---

## 9. 公开规则与潜规则

```yaml
规则系统:
  公开规则:
    - 写在制度里的规则。
    - 人们公开引用的道德语言。
    - 仪式上被赞美的价值。

  潜规则:
    - 真正决定人命运的规则。
    - 人们私下使用的判断标准。
    - 谁都知道但不能承认的交换。
```

每条公开规则都应该有对应潜规则。

```yaml
公开规则: 学术评价应当公正透明。
潜规则: 谁被认为“难带”，谁就会提前失去机会。
```

---

## 10. 共同秘密

小镇必须有共同秘密。共同秘密不一定所有人都知道全部，但每个人都知道某一部分。

```yaml
共同秘密:
  秘密名称:
  表面版本:
  真实版本:
  谁知道全部:
  谁知道一半:
  谁误解它:
  谁靠它获利:
  谁被它毁掉:
  它如何影响当前人物:
  它最可能被什么事件触发:
```

共同秘密的功能：

- 让过去进入现在。
- 让人物之间有债。
- 让谣言和证据变得危险。
- 让新事件不是随机，而是旧伤复发。

---

## 11. 历史伤口

历史伤口不是背景故事，而是仍在行动的过去。

```yaml
历史伤口:
  过去发生了什么:
  当时谁沉默:
  谁获利:
  谁背锅:
  谁离开:
  谁留下:
  今天谁还在维护谎言:
  今天谁想重提:
  今天谁最怕重提:
```

---

## 12. 谣言系统

小镇必须有谣言系统，因为复杂关系需要被外界误读。

```yaml
谣言系统:
  谣言传播场:
    - 食堂
    - 走廊
    - 教师休息室
    - 微信群
    - 学生论坛
    - 家族饭桌
    - 值班室

  谣言生成规则:
    哪些行为最容易被误读:
    谁最擅长放大误读:
    谁表面辟谣实际扩散:
    谁能用沉默坐实谣言:
    谁能从谣言中获利:

  谣言类型:
    欲望谣言:
    权力谣言:
    金钱谣言:
    背叛谣言:
    道德谣言:
    精神状态谣言:
```

## 13. 证据系统

证据系统让人物行为留下痕迹。

```yaml
证据系统:
  证据类型:
    - 邮件
    - 批注
    - 监控
    - 录音
    - 照片
    - 成绩记录
    - 借阅记录
    - 医疗记录
    - 聊天截图
    - 会议纪要
    - 修订记录
    - 失物
    - 礼物
    - 账单
    - 旧信

  证据规则:
    哪些证据容易被误读:
    哪些证据能证明事实但不能证明动机:
    哪些证据看似无害但放在一起危险:
    谁能删除证据:
    谁能伪造证据:
    谁能保护证据:
```

关键原则：

> 外部证据可以误读事实，但读中关系结构。

    - 办公室门口
    - 候车厅

## 18. 公共仪式

公共仪式是逼人物表演身份的场景。

```yaml
公共仪式:
  仪式名称:
  表面意义:
  隐藏功能:
  谁必须出席:
  谁害怕出席:
  谁会利用这个场合:
  谁可能失控:
  哪个秘密最容易爆发:
```

示例：

```yaml
公共仪式:
  仪式名称: 年度优秀教师评选答辩。
  表面意义: 表彰教学贡献。
  隐藏功能: 让所有人公开确认某种道德叙事。
  谁必须出席: 候选教师、系主任、学生代表。
  谁害怕出席: 曾被候选教师不公评价的学生。
  谁会利用这个场合: 想保住学院声誉的人。
  哪个秘密最容易爆发: 评价权被私人欲望污染。
```

## 25. 反扁平场所规则

禁止以下场所：

- 只有氛围，没有压力。
- 只有地图，没有权力。
- 只有秘密，没有知道秘密的人。
- 只有规则，没有潜规则。
- 只有背景历史，没有今天仍在行动的旧伤。
- 只有事件，没有证据。
- 只有冲突，没有谣言。
- 人物可以轻易离开。
- 场所不能误读人物关系。
- 场所不能逼人物公开表演体面身份。
