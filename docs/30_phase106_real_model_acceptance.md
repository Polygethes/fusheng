# Phase 106 真实模型验收

## 结论

Phase 106 的产品修复已完成：当前 v2.7 人物链能够在同一持久世界中，由各自感知、私有记忆、心理、计划与实际世界后果连续生成自然的短程行为和对白；不存在脚本替人物选台词、维护回合冒充世界行为、未送达信息直接进入认知或失败输出先污染世界的问题。

本结论是 **GTOWN 的短程真实样本 + 长程确定性架构验收**，不是 Stanford 官方认证，也不冒充 `29_stanford_generative_agents_reference.md` 中预登记的 30 窗口盲评和多种子社会运行。

## 授权与运行

- 模型：`gpt-5.6-sol`
- 推理：`high`
- 目标：6 个 Character actor turns
- 硬预算：每回合最多 5 次，累计最多 30 次 provider 请求

- 协议修正：1 次；最终运行失败：0

原始报告包含人物私有上下文和作者审读心理，只保存于权限为 `0600` 的临时文件，不进入仓库。本文件仅保留公开行为、汇总指标与去私有化审计结论。

## 真实运行发现并修复的问题

### 1. 日计划 schema 与 OpenAI 不兼容

第 2 回合首次尝试时，OpenAI 在生成前拒绝了 `planBlocks[].sourceIds.uniqueItems`。该失败计为累计第 5 次请求，但没有提交人物或世界事务。

修复后，供应商 schema 不再发送 `uniqueItems`；服务器 settlement 继续对来源去重并校验 owner。恢复严格使用原 durable checkpoint，累计计数从 5 接续，没有重放已完成的洛照回合。全部 8 个真实人物阶段现有递归兼容关键字回归。

### 2. 未知人物表征被语言习惯补全

公开对白没有性别错误，但作者可见心理中出现过把尚未明确性别的陌生人写成“他”。通用人物提示现要求：身份、称谓、年龄、性别或关系未被本人当前感知和记忆明确提供时，只使用“来人、对方、此人”等中性指代。该规则同时覆盖主观评价、候选、选择、表达计划、实现和原子提交。

### 3. 质量报告口径可能误导

旧报告把 `floor(actorTurns / 2)` 命名为 two-way exchanges，并把作者可见心理放进名称含糊的 `visibleExchange`。报告 v2 已改为：

- `actorTurnPairsCompleted`
- `spokenTurnsCompleted`
- `causalSpeechRepliesCompleted`
- `conversationThreadsObserved`
- 纯公开 `publicExchange`
- 私有 `authorReviewTurns`

失败 command 也会从 execution metadata 回填实际 stage 与请求消耗。
