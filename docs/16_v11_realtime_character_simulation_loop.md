# v1.2 真实模型实时模拟编排

## 设计动机

“计划碰撞调度器”容易把人物变成规则系统。斯坦尼式运用应该让人物在规定情境中行动，而不是让系统先安排他们的剧情功能。

v1.2 因此把“计划碰撞”改成“实时人物模拟”：计划仍然存在，但它只是人物进入场景前对自己的谎言；真正的戏剧来自计划与现场、记忆、他人反应、场所压力之间的破裂。

## 核心单位：SimulationTick

每次播放都会创建一个 `SimulationTick`。

```json
{
  "id": "tick_xxx",
  "grain": "scene",
  "mode": "tick_based_realtime",
  "locationId": "loc_xxx",
  "activeCharacterIds": [],
  "visibilityLayer": {},
  "privateSimulations": [],
  "contradictionPressureSummary": {}
}
```

## CharacterPrivateSimulator

每个人物先独立生成私人后台：

```text
公开目标
私人欲望
防御面具
阴影冲动
高尚冲动
自欺句
行动候选
想从别人那里得到什么
不愿承认什么
会制造什么风险
计划张力
记忆张力
可见性盲点
矛盾压力
```

这一层不能替别人行动，也不能替故事收束。

## VisibilityLayer

可见性层回答：

```text
谁知道什么？
谁误以为什么？
谁故意隐藏什么？
谁的盲点可能被看穿？
什么证据、谣言、秘密、不可逆痕迹正在改变现场？
```

这让人物不再拥有全知视角。深度来自他们用错误信息行动。

## SceneInteractionSimulator

场景互动模拟器不安排剧情结论，而是把多个私人后台放进同一个可见场所：

```text
A 的私人意图
→ B 的误读
→ B 的反行动
→ A 的防御变形
→ 场所把私人动作转成公共压力
→ 留下不可逆痕迹
```

## DepthAuditor 新规则

审查器必须抓住以下失败：

```text
人物没有私人后台，只是响应场景。
计划被机械执行，没有被别人误读或被自己背叛。
导演直接安排深度，覆盖人物私人意图。
可见性太完整，缺少误读和隐藏事实。
场景没有让私人意图在对方反应中破裂。
```

## 最重要的一句话

```text
计划不是剧情。
计划是人物进入场景前对自己的谎言。
```
