# 经验基座：从望梯酒馆落成的通用规则

日期：2026-10-09。来源：《逍遥游·望梯酒馆》从 20 回合到 1000 回合的长测、复核与修复（docs 38–50 与各次运行 PLAYBOOK）。

这里每条规则都与具体世界无关。新世界通过世界包接入同一运行时（`src/worlds/<id>/pack.mjs`），由 `npm run world:validate` 静态检查、`npm run world:smoke` 用真实世界结算做零模型冒烟。规则后面写明证据、执行它的代码，以及对新世界生效的检查项。

| # | 规则 | 证据 | 执行它的代码 | 新世界检查 |
|---|---|---|---|---|
| 1 | **说了不等于做了。** 物品、位置、声音、时间和工作完成只由世界结算产生；人物说“柴都劈完了”只是一句话。 | 44：78 回合文字宣称劈柴，成柴始终为 0；45 G1/G8 | `worldActionRegistry`、`workCapability`；46 取消 `act` 自动成功 | V2：每个时限都有能改变客观状态的工作路线；冒烟用真实结算达成 |
| 2 | **触碰不是工作。** `interact` 只记触碰；工作必须开始、过程就绪、再收尾，那一回合才改资源。 | 48；21 号运行 PLAYBOOK 第 51–70 回合 | `workCapability` 开始/收尾两步、`objectPhysicalObservation` | V3：工作模板写入的状态键真实存在；冒烟逐单位完成 |
| 3 | **工具要真的在手里。** 没拿斧头不能劈柴，空桶不能添水；放下一件东西不会顺带移动另一件。 | 46 §2；21 号运行第 18、23 回合 | `heldRequiredTools`、物件账本 | V2/V3：工具物件存在；冒烟先取工具 |
| 4 | **时限要有客观条件。** “答应了”“描述做完了”都不能抵账；到期未齐记延误，迟到补齐记迟到完成。 | 47；45 G8 | `worldTemporalAgenda` | V2：无条件的时限被拒；冒烟检查按时 `fulfilled` |
| 5 | **私人安排不是全场公告。** 只有知情者看见时限、收到提醒；“谁知道”本身是剧情。 | 借星：小满开场不知道午时接引舟 | `knownByActorIds`（`worldTemporalAgenda`） | V2：负责人或知情者必须在场 |
| 6 | **能力边界由世界结算，不由剧情决定。** 缺少技能的尝试结算为 `WORK_SKILL_MISSING`，世界不变，也不替人物换动作。 | 借星：父母不是剑修，小满修阵失败 | `workCapability.requiredSkillIds` | V2：负责人具备所需技能；冒烟证明边界两向成立 |
| 7 | **等待不得空耗调用。** 等待登记条件和期限后休眠，只由真实事件、截止点或身体变化唤醒。 | 39：41–50 回合十次“稳住继续等”；44：后 78 回合无对白 | `characterExecutionControl`、`waitMatchesWake` | V5：至少一项跨人物事务，避免开场即进入等待均衡 |
| 8 | **欲望要落地。** 每个人物至少一个欲望指向开场在场的人、物或地方（或手上有待交接的东西）。 | 39、44：缺少落地对象的人物只会观察与休息 | `validateEcologyDesire`、欲望落地投影 | V4 |
| 9 | **关系变化需要第一手证据。** 没收到证据时不提供“关系变化”选项；传闻不自动变成第一手。 | 49；本基座修复的不可满足 schema | `characterAgentTurnProtocol` 关系校验、`tavernCharacterAgentV2` 生成约束 | 冒烟扫描所有首阶段约束是否可满足 |
| 10 | **人物自主，程序不代选。** 错误输出只能要求同一人物修正、记录失败或暂停；不能自动选最高分候选或用模板补写。 | 39：自动驾驶模板替人物选择；50：1000 回合后段模板生成 | 三阶段协议、`authorizeCharacterTurnRetry` | 入口层：中继默认只能排练 |
| 11 | **修复与恢复有界且留痕。** 修复额度写进存档，重启不清零；恢复须显式授权编号与原因，已接受阶段不丢。 | 49；21 号运行第 41–50 回合挂起事故 | `characterTurnExecution` | — |
| 12 | **重复循环要停下。** 最近 24 回合中至少 12 次公开行动只有 ≤3 种组合且无实际效果，停机并保留现场。 | 50 | `simulationIntegrity` | — |
| 13 | **来源如实标注。** 中继回复是“外部·未验证”；网关声明的模型不是独立认证；回合数用满不代表故事完成。 | 50 | `settledSimulationReport`、各入口 provenance | 观察台来源徽标 |
| 14 | **报告只列已结算事实。** 意图、拒绝稿、私人信念不作为已发生的行为。 | 41 §9 | `settledSimulationReport` | V8：报告指标指向真实状态 |
| 15 | **悬念不写成真相。** 原作保留的未知，不得成为任何人物心中已确认的事实。 | 借星世界观设定集 §5.3 编写警戒 | 世界包 `mysteries` | V7 |

## 新世界接入步骤

1. 信标原文放入 `src/worlds/<id>/beacon/`，选场理由与暂定补设写进 `README.md`。
2. 写 `pack.mjs`：舞台拓扑、阵容（含 `ecologyProfile`、`skills`、`appearance`、`voiceBlueprint`、初始记忆）、物件、工作、社会规则、时限、悬念、报告指标、像素布局。
3. `npm run world:validate -- <id>` 全绿。
4. `npm run world:smoke -- <id>` 全绿：每个人物的首阶段可生成且约束可满足；每个时限能被知情者按时达成；技能边界成立。
5. `npm run world:new -- <id> --out sim-runs/<新目录>` 建立 0 回合世界，在像素观察台授权后开跑。

## 仍然不能保证的

- 模型是否聪明、自然、愿意推进故事。基座保证的是：错误不会变成世界事实，消息不会静默消失，无进展不会无限消耗，暂停不会伪装成完成。
- 冒烟里的“驾驶员”只证明可达性，不是人物行为证据，也不写入任何存档。
