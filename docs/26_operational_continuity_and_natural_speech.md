# Character Agent v2.5：自身行动连续性、语言冲动与自然发声

## 1. 本次修复的两个根因

### 1.1 人物做过，却没有以“我做过”进入本人

世界账本已经知道一壶茶由谁交付，但旧投影主要依赖“谁是来访 host”。当实际服务者不是 `hostId` 时，人物会在客观上完成送茶，却在下一次 Agent 输入里同时缺失：

- 本人参与的已结算交易事实；
- 近期自身行动；
- 带本体感来源的自身行动记忆。

因此重复询问不是人物故意重问，而是世界结算到人物第一人称连续性之间断桥。

### 1.2 台词把后台规划表念了出来

旧言前计划容易把“限定消息类别、给出道路／山门／行程信息”当成语言冲动。最终发声阶段虽然知道人物声音，却收到了一张行政分类表，只能把它改写成稍像古语的表单答案。

此外，普通问答被登记成需要双方同意的 `brief_service_conversation`，让一次自然交谈带上了提议、接受、协调和访问许可等不必要的程序状态。

## 2. 新的连续性链

```text
世界客观结算
  → 带 actor/action/object/participant 来源的 interaction event
  → 按人物与业务分支过滤后的 material facts
  → 本人行动进入一次且仅一次的第一人称情景记忆
  → recentOwnActions + settledSharedEvents + literalPublicTurns
  → Character Agent 自己理解、相信、遗忘、歪曲或承接
  → Character Agent 自己选择行动并形成自动语言冲动
  → 心理数学工具计算人物所选调节的余量与残留
  → 同一 Character Agent 形成调节后的表达计划
  → Character Agent 用自己的身体和嗓子实现
  → 世界只结算可观察结果
```

世界只提供“发生过什么、谁参与、来源是什么”。它不因此决定人物相信什么，也不禁止人物撒谎、装傻、记错、逗弄或重新发问。

## 3. 操作事实采用分支知情，不采用全知 host

同一次来访被拆成可独立知情的分支：

- 服务请求、准备、交付与消费；
- 付款；
- 货物交接；
- 住宿安排；
- 来访事务；
- 以工换饭。

人物只获得本人参与、本人来访或其公开职责应知的分支。例如谢真石亲手送茶，就知道茶已经送到；但这不使他自动知道洛照未说明的真正来意，也不使他知道别人经手的付款细节。

## 4. 记忆、认知与说话继续分层

`discourseContext` 只提供三类锚点：

1. 已结算的共同经历；
2. 本人刚完成的行动；
3. 双方实际说出口的字面话语。

字面话语不自动等于事实。人物仍通过自己的记忆和心理模型判断可信度，也可以选择：

- 当作已给定并自然省略；
- 为澄清而重开；
- 质疑记忆或真实性；
- 逗弄、欺骗、误记或虚构；
- 不回答或转开。

区别只在于：重复或矛盾现在应当来自人物的认知与交往选择，而不是输入断链。

## 5. 自然发声不是句式模板

人物选择行动时，先形成一个尚未被调节、也尚未成为台词的自动语言冲动：

- `triggerEvidenceIds`：究竟什么被本人感知的事实触发了它；
- `perceivedTurnDemand`：这个人物觉得眼前时刻在向自己索取什么；
- `feltTendency`：最先想承认、反问、堵回去、回避或沉默的语义—情感方向；
- `urgency / disclosurePressure / inhibitionPressure`：人物自己对冲动强弱的内在读数；
- `motiveSourceIds / conflict`：这股冲动来自本人的哪些欲望、价值、关系或记忆，又被什么相反倾向牵制。

人物选择调节后，心理数学工具只计算控制余量、调节成本与仍会泄漏的通道。随后仍由同一个人物 Agent 决定如何处理冲动，并形成调节后的言前时刻：

- `currentTurnDemand`：眼前真正需要处理什么；
- `regulatedOpeningMove`：经过本人调节后，实际准备如何开口或不说；
- `minimumPublicDelta`：只增加一件足以让互动继续的具体内容；
- `expansionFunction`：若还要多说，额外话语实际承担什么功能；
- `deferredOrImplied`：留在潜台词、动作或以后再说的内容；
- `nonverbalUndertone`：由视线、停顿、呼吸、节奏和动作承载的情绪。

最终发声只看调节后的公开表达表面和人物嗓音，不再读取原始冲动文本、完整心理账或私密调节理由，也不逐条翻译心理报告。没有统一短句限制，也没有为洛照、谢真石预写“正确台词”。人物在说服、警告、教导、安慰、谈判、正式承诺、刻意施压或情绪失控时仍可说得很长。

## 6. 对话线程与共同活动分工

普通问、答、回避、撒谎、沉默和顾左右而言他属于对话线程，不要求双方先同意“进行交谈”。

只有话说完后仍需共同执行和持续结算的事情进入 `sharedActivity`，例如：

- 交手或共同练习；
- 带路、护送与跟随；
- 合作办事或共同任务；
- 需要双方接受的持续条款与范围。

这样既保留双方 Agent 各自的同意权，也不会让自然问答变成行政流程。

## 7. 验收边界

本地合同可以证明：

- 人物收到自己做过的已结算行动；
- 相同行动不会被重复写入记忆；
- 隐私不会因经营参与而整包泄露；
- 共同语境到达言前计划和最终发声；
- 故意撒谎、误记、逗弄和重开仍合法；
- 普通对话不会制造伪共同活动；
- 数学工具仍不生成或选择台词。

四轮双 Agent 测试现在需要 `5 stages × 8 activations = 40` 次阶段调用；旧 v2.4.x 的 32 次报告只能作为历史证据，不可续跑成 v2.5。

本地合同不能证明台词已经“好听”或“像真人”。这仍需新的真实模型连续样本，并由作者直接判断人物情绪、关系、声音和互动质感。
