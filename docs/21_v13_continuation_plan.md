# v1.3 持续升级方案：人物底座、运行权威与真实感验收

## 0. 结论

v1.3 不是“继续给酒馆补规则”，而是把已经暴露的责任混乱拆开，再用酒馆证明底层能力：

```text
作者层：确认事实、价值、欲望、关系、语言与故事开放轴
人物底座：保存可运行的人格/心理参数，不保存情境答案
通用认知内核：从当下感知和世界 affordance 形成候选，作为人物私人工具
Character Agent：作最终选择，决定行动、说话或沉默
世界层：提供客观事实、机会、社会压力、物理可行性与后果
评估层：外部判断自然度，不回写人物答案
Writer/Director：最后接入的外围层，不是当前人物问题的替代方案
```

“因果测试通过”只能证明一些错误被拦住，不能证明人物已经活了。v1.3 的验收必须同时保留三种不同证据：

1. 结构/因果合同；
2. 真实模型运行证据；
3. 作者与外部读者的盲评判断。

## 3. 主线 M

### M0：人物底座边界（本轮完成）

- 作者证据总账、运行 foundation、calibration suite、owned memory 四件套；
- foundation 白名单投影；
- calibration answers、Holdouts、exact speech samples、situation-to-action scripts 不进入 Agent；
- generic cognitive core 从 perceived affordances + universal primitives 形成候选；
- 七包物理迁移不改变 gate 状态。

验收：boundary/workflow/runtime/hash/behavior 回归通过；污染 foundation 的反例被 checker 拒绝。

### M1：完成剩余人物锚定

逐人完成事实、欲望、自我威胁、阻碍、认识边界、表达倾向、关系维度、owned memory 和三个未见 Holdout。

规则：

- 作者回答用于推断机制，不直接写未来动作；
- 未确认 Holdout 不计 passed；
- 不复制洛照、谢真石或周珉的权重/语言/行动；
- 场景 binding 只说明人物为何在此、知道哪些 affordance，不预排出场时段。

验收：每个 manifest 的 gate 与真实证据一致；只报告已完成的人物，不以“七个目录存在”冒充七人完成。

### M2：唯一运行权威与 legacy 退役

- validated 人物逐个切到 `characterFoundation + owned memory`；
- legacy static anchor 与 unified packet 合并，不并存为两个 live 真相；
- 清除或降级 `agentProfile/lifeState` 中未经作者确认的年龄、关系债务、物件史、羞耻机制和固定语气；
- 旧字段只作有期限的 migration adapter，并记录调用点下降曲线。

验收：每个状态只有一个写入权威；Agent 输入中无 authoring/calibration sentinel；legacy 命中为 0 后才删除适配器。

### M3a：社会惯例与 affordance advertisement

把住宿、验货、点单、结账、以工换饭、找人、请教、举荐请求等表达为：

```text
公开角色 + 所需物件/区域 + 可见步骤 + 完成证据 + 可中断状态
```

惯例只向当事人广告当下可做什么，不规定人物必须接待、必须付款、必须回答或必须离开。

验收：人物能找到与场所关系相关的事；多来意分别保留开放状态；事务完成不关闭人物私人欲望。

### M4：连续时钟与会话锁

- 宏观时段只作环境参数；
- 事件使用连续时间戳、预计耗时与反应延迟；
- 直接问答保持同一 conversation id；
- 对方已离开、听不见、没有前置 utterance 时不能生成回答；
- 步数上限只暂停计算，不自动推进时段。

验收：普通连贯问答不跨小时；延期、沉默、转身或离开都是人物实际选择；没有“承接未来时段不存在的对话”。

### M3b：可中断 micro-plan

只在 Agent 已选择一个确实需要多步的意图后生成 2–5 步局部计划。每步重新检查对象、位置、物件、会话、身体和新影响；失败则中断或回到 Agent 重规划。

验收：计划不锁死结局，不把 social practice 变成流程脚本，不在对象已完成/离开后继续执行。

### M5：行动后反馈

每个 committed action 统一更新：

- 物件、位置、时间与资源；
- 身体消耗与恢复；
- 欲望进展、满足、受阻与挫败；
- 人物主观 appraisal；
- 有证据的关系维度；
- 可传播影响与氛围；
- owned memory 与开放承诺。

observer psychology 可以显示因素和未选候选，但不能成为人物或 Director 的新事实来源。

### M6：场外接口

第一版只维护位置、行程、返回意图、场外已提交事实与未完事务。不自动生成完整场外剧情；当第二个真实场景接入时再从实际差异提炼通用接口。

## 4. 真实感线 Q

### Q1：先冻结评审协议，不先优化分数

- 固定若干酒馆初态、随机种子与可见输入；
- 保存新旧版本匿名输出；
- 作者与至少一位非作者读者独立评审；
- 评价维度包含：因果连贯、欲望可感、行动质感、语言身份、关系连续、身体影响、是否像被安排；
- 遮名猜人物只是一项诊断，不能作为唯一目标。

在看新版本结果前冻结样本、题目、评分含义和弃权/两者都差的语义，防止评审协议随输出移动。

### Q2：动机表达与潜台词

取消“欲望关键词不得出现在台词”的硬禁令。真实人物有时会直说，关键是表达是否符合：

- 当前目标与证据；
- 关系安全度和隐私；
- 暴露/解释成本；
- 压力阈值；
- 人物一贯的语用功能。

自动检查只拦后台语言、无来源自白和与当前信念矛盾的说明。潜台词强弱由盲评与 factor trace 共同诊断，不用关键词零违例刷分。

### Q3：沉默、不作为与非语言行动

观察、等待、继续手头事、压住话、换位置、离开都必须是有对象/目标/持续时间/结束条件的行动候选。

不设“每场非对话行动占比”硬配额。报告行动类型分布、功能、持续时间及评审判断；该说话时强行沉默和该沉默时强行说话都算失败。

### Q4：身体状态传导

身体状态进入 appraisal、动作成本、披露耐性、句式参数和行动幅度。用成对反事实测试检查同一人物在 rested/strained 状态下是否产生有因果依据的变化。

不要求所有疲劳输出都能被盲猜中；相似反应有时也合理。报告一致性、变化方向、过度表演和无变化四类结果。

### Q5：Sifter 活性诊断

W1 完成后报告候选 thread、误报、漏报、开放目标进展和长期停滞。不得把“每天至少一条 thread”设为 Director 或人物优化目标。

## 5. 人物编译器线 C

### C0：分层 schema（本轮完成，仍为 provisional）

当前四件套已经建立必须边界，但字段集合不能在其余人物尚未锚定时宣布最终冻结。

### C1：从七人差异修订基座模板

| 层 | 内容 | 权威 |
|---|---|---|
| 必填 | 身份、前史、正向自有欲望、满足证据、底线、关键关系期待 | 用户/权威材料 |
| 可选 | 创伤/敏感触发、身体差异、说话倾向、开放选择轴 | 用户/材料；未知可保留 |
| 编译 | 参数范围、阈值、惯性、衰减、聚合声纹 | compiler，保留来源 |
| 测试 | controlled contrasts、speech samples、Holdouts | calibration suite；不进 runtime |

验收不是“七人都能塞进 schema”，而是 schema 能表达差异、未知、冲突和 story-open choice，同时不含未来行动答案。

### C2：第八人物试验

- 模型先生成 draft，不得自动 confirmed；
- 语义门拦截否定欲望、职责冒充欲望、目标主体颠倒、知识越界、称呼/关系角色混乱和运行层泄漏；
- 只把高信息增益问题交给作者；
- 用与前七人相同的 Holdout 和真实模型场景验收。

报告作者问答轮数、修正次数、误补事实数、Holdout 通过迭代和最终自然度。目标是显著降低成本，但不设 `≤ 1/5` 的硬门，避免编译器通过少问问题来制造未经确认的人物。

### C3：用户界面

只在 C2 证明“减少提问不降低人物质量”后再做。Director T4 访客复用该流水线，但 Director 无权自动确认人物事实。

## 6. Writer 与 Director 衔接

- W0 可在 M1 同期做只读 story query；
- W1/W2 在 M5 后做，避免用尚不完整的反馈日志训练错误叙事模式；
- D0 在 M5 后只做 observer-safe 遥测；
- D1 在 D0 可回放且人物反馈闭环稳定后，才开放守夜 T1–T3；
- T4 依赖 C2；T5 只提交危险起因并需用户批准。

详见 `docs/20_director_writer_upgrade.md`。

## 7. 指标与证据等级

| 项目 | 合同证据 | 真实运行证据 | 人类判断 |
|---|---|---|---|
| 对话目标/位置/前置话语合法 | 必须通过 | 抽样复核 | 可报告违和 |
| 欲望持续与关系更新 | 状态回归 | 多轮轨迹 | 是否可感且自然 |
| 语言身份 | 禁后台/样句泄漏合同 | 遮名样本 | 作者/外部读者判断 |
| 身体传导 | 成对反事实合同 | real-model paired run | 是否过度或不足 |
| Sifter | provenance/单向阀 | 固定存档查询 | 命中、误报、漏报 |
| Director | occurrence gate/禁令 | 关闭/守夜对比 | 是否像操控剧情 |

不再使用以下硬目标：关键词违例为 0、非对话比例、疲劳必须可盲猜、问答轮数 ≤1/5、thread ≥1/日。这些量可以报告，但不能替代质量判断。

## 8. 工程卫生

- 当前 415 个 script alias / 389 个 test-suffixed alias 只作清单快照；先建立分组 runner 和失败归属，再讨论总测试数；
- 逐步归档超长 `task_plan.md/progress.md/findings.md`，但保留当前 Phase 与证据链接；
- 单仓库、tag 与远端备份是工程任务，不和人物真实感 gate 混成一个验收；
- 本轮 additive migration 保留 v1 author payload，直到 registry 切换完成后再决定是否归档。

## 10. 本轮决定

```text
先解决人物底座与运行权威，再解决节奏和成文。
先让候选来自当下世界，再让人物自己选择。
先冻结评审协议，再看版本分数。
指标负责诊断，不负责替作者宣布人物已经活了。
```
