## 选场

**十二岁离家那天的清晨，卯时三刻**，介于第一集场景十（后半夜药房）与场景十一（清晨出发）之间。

- 家里压力最密：昨夜修阵失败、父亲双手灼伤、丫丫在药房昏睡、接引符刚续上剑宗印记、母亲决定送到归云岭、阿宝要来送别。
- 结构接近已被长测锤炼的“家计 + 劳作 + 时限”，风险最低。
- 受保护场景“主动求学”留给人物自己：世界只摆出事实和时辰，不替小满决定去不去。

备选未做：青岚渡接引舟（需大量新增陌生人，高潮是人物左右不了的袭击）；八岁夜游（独角戏，缺互动）。
