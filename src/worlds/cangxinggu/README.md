# 借星 · 雨夜入谷（世界包 `cangxinggu`）

本世界是基于小镇蓝图系统构建的内置世界包。故事回到最初的原点：暴雨之夜，顾家年轻夫妇抱着襁褓里的新生儿逃难摸进藏星谷。

## 用户的三条要求

1. **整个藏星谷地图与合理人物**：不再局限于顾家一隅，展开包含溪流、石桥、梯田、药田、私塾、祠堂、阵眼等 18 处地点的整座藏星谷，并补齐 10 位性格各异的谷中居民。
2. **从逃难入谷那一夜开始模拟**：故事从秋末暴雨倾盆、戌时初（19:00）顾家夫妇逃入山口废屋的时刻开场。
3. **资料只当设定，不当故事线**：用户提供的《借星》背景资料仅作为世界观与环境设定，不预设后来的剧情走向与既定命运，人物将来的际遇由城镇生态模拟自然衍生。

## 设定与未引入的故事线

### 资料中作为设定的部分
- **藏星谷地理与生态**：四面环山的小谷地，溪流在东、松林在西、北坡有阵石、南面是梯田与药田；谷中夜晚有发光的灵草、后山有灵鹿；烟火气重，住着数户人家。
- **天然地脉与护谷阵**：依靠北坡阵石借助地脉藏住整个山谷，能使凡人与外来修士在周围群山迷路，但并非不可破的护罩。
- **人物本领与来历**：顾怀山擅长阵法和木工，陆青禾擅长医术与草药（二人皆非剑修）；谷外兵荒马乱，夫妇二人携幼子持玉符冒雨避难而来。
- **开场意象**：雨夜破屋、符火护门、丹火取暖照料婴儿，以及一把能止住婴儿啼哭的锈蚀短剑。

### 未写入的故事线
- 剧本后续涉及的仙门选拔、宿命离别、少年成长等既定情节一概不写入蓝图。
- 谷中众人的命运走向、顾家夫妇是否能被藏星谷接纳，完全由模拟系统中的人物动机、作息与交互自行发展。

## 保留的悬念

- 这对夫妇是怎么找到进谷的山缝的？
- 北坡阵眼的光为什么偏偏今晚暗了？
- 那把生锈的短剑为什么能止住婴儿的哭？
- 陆青禾的引路玉符原本是谁的？
- 他们在山外到底逃的是什么？
